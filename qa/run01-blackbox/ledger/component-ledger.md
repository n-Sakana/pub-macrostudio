# 操作台帳（全画面 × 全可視コンポーネント）

- v1: SPEC §2.2 / README / `assets/js/screens.js` / `assets/js/screens/workflow.js` / `assets/js/app.js` の
  可視文字列から起こした**暫定版**。
- P1 の実画面 recon で、実物に出た全コンポーネントを追記して確定する。
  実画面にしか無いもの（トースト、ダイアログ、スクロール器、カード、フォーカス環）は
  recon 後に必ず追加する。
- 「操作」欄の記号: `→` 一方向 / `⇄` 双方向 / `×N` 反復 / `[cond]` 出現条件を作ってから操作

| 列 | 意味 |
|---|---|
| ID | 台帳 ID（`S<画面>-<連番>`） |
| 種別 | btn / link / check / radio / text / select / accordion / card / toast / dialog / scroll / dnd / kbd |
| 操作計画 | 実施する操作列（双方向・反復・順序変更・別状態からの再操作を含む） |
| 撮影 | pre/post を撮る操作番号 |
| 結果 | P2 以降で記入（OK / NG-<ID> / 到達不能+根拠） |
