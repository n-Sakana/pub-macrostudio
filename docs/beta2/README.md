## この版で変えること（要旨）

1. **トップレベルの分岐を消す。**「AIで改修」「AIで相談」「簡易モード」の 3 入口を廃し、
   *読み込む → 診断する → 決める → 実行する → 差分を見る → コピーを出力する* の 1 本にする。
   一時期この分岐を「マクロ改修 / リファクタ / フリー依頼」の 3 入口として戻したが、
   同じ理由で撤回した（6）。
2. **第 1 段階を事実監査にする。** VBA 全文＋想定動作環境を AI へ渡し、機械契約で検証した
   診断結果を受け取る。この段階では改修方針を決めない。
3. **想定動作環境を実データにする。** `environment/target-environment.json` を実行時に読み、
   欠落・不正なら fail-fast する。コード内に埋め込まない。
4. **決定的置換エンジンを足す。** ユーザーには「固定パスを新環境へ置き換える」という
   ひな形 1 枚として見え、内部でだけ AI ではなく決定的エンジンへ dispatch する。
5. **UI を一つの中央作業面にする。** 主結果を先に、証拠と技術詳細を淡い第二層に、
   任意入力はその場で開く折りたたみに置く。別画面・別モーダルへ追い出さない。

## 変えないこと（β1.10 から持ち越す不変条件）

- 原本非破壊。出力は常に別名の新しいブックで、実行フォルダの中だけに作る。
- 依頼 ID（UUID v4）による依頼と返答の対応付け。別依頼の返答は受理しない。
- AI 返答は厳格な機械契約として検証する。部分・不正形式は黙って受理しない。
- 添付時点との VBA 内容署名一致（E-BUILD-04）。書き戻し後の読み直し検証。
- 全モジュールを常に渡す。載せるモジュールを人に選ばせない。
- WebView2 の境界（信頼 origin・遷移拒否・DevTools 無効・host object 無し）。
- 外部依存ゼロ。dotnet SDK 不要。フォルダをコピーするだけで動く。
- 公開済み GitHub Release `v1.1.0-beta.1` と `public-release/package/` は一切変更しない。
